\section{Arquitectura del sistema}

P\'arrafo de cuerpo con la medida de l\'inea y el interlineado del documento.
Esta misma plantilla se repite en todas las hojas interiores: encabezado con
la marca y el t\'itulo, una sola columna de texto y pie con numeraci\'on.

\subsection{Componentes}

Los t\'itulos van numerados y en la tipograf\'ia de encabezado; el cuerpo
mantiene el mismo tama\~no en todo el documento.

\begin{itemize}
  \item Servicio de API y autenticaci\'on
  \item Base de datos y capa de persistencia
\end{itemize}
